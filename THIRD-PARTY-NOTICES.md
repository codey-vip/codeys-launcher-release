# Open-source attribution

The launcher is adapted from **tom-weiland/csharp-game-launcher**:

- Source: https://github.com/tom-weiland/csharp-game-launcher
- Upstream commit: `66c85ff71cee322373383c7d25e42b7b5d2f7066`
- License: MIT, Copyright (c) 2020 Tom Weiland.
- The original license is retained in `Licence.txt`.

CODEYS replaces the sample game's download/update workflow with its own account
API, native game connection bridge, client validation and Chinese interface.
The sample's game, artwork and remote download URLs are not used by this product.

The self-contained Windows build includes Microsoft .NET / Windows Desktop runtime
components and their accompanying license notices. No third-party game client,
game resources, game server keys or database credentials are included.
