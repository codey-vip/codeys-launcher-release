CODEYS 无限法则启动器

适用：Windows 10 / 11，64 位。解压后运行 CodeysLauncher.exe。完整版包含运行环境；精简版需要 .NET 10 桌面运行环境（x64）。
当前正式版为 1.1.8，旧版必须更新后才能继续启动游戏。
无需旁边的 app 文件夹。双击后先显示加载图标和动态进度条，主界面出现后自动收起。

启动器根目录只需保留 CodeysLauncher.exe，附属文件集中在 CodeysLauncher.Data 文件夹：
logs 存放日志，updates 存放更新期间的临时文件与回滚备份。成品包不含 docs 文件夹；中英文指南与许可可在公开仓库查看。
旧版散落的启动器日志、指南和许可会自动归档；其他个人文件不移动。
每次启动会在 CodeysLauncher.Data\logs 生成两份同时间的 .log 文件：
CodeysLauncher-日期-时间-毫秒-进程号.log：启动过程、操作、错误堆栈及网络检测结果。
同名 .runtime.log：主程序尚未打开时的运行环境错误；正常启动时可能为空。
出现问题后关闭启动器，把同一次启动的两份 .log 文件交给维护者即可。
设置内的“使用帮助”会显示本次日志的实际路径。文件夹不可写时自动改存到
%LOCALAPPDATA%\CodeysLauncher\logs；两处均不可写时仍会继续尝试启动。
日志不记录账号密码、登录令牌、游戏票据或网络数据包。检测到错误时，会自动把
本次主日志和运行时日志的脱敏摘要上传到 codeys.vip 私有诊断目录；正常会话不上传。
原始本地日志保留。断网时暂存在 %LOCALAPPDATA%\CodeysLauncher\diagnostic-uploads，
下次启动按退避时间重试；最多保留20份待传报告、14天。上传不会阻塞界面或退出。
主日志上限4 MiB；每次启动自动按启动时间只保留最近10次启动，
同一次启动的主日志、运行时日志及错误/崩溃日志作为一组，超出后一并删除。
正在使用的日志会等文件释放后在下一次清理。主界面尚未打开的崩溃也计入10次。

1. 访问 https://codeys.vip/ 注册自己的账号。
2. 在启动器输入账号名或邮箱、密码登录。
3. 启动器会自动识别游戏目录；未找到时，手动选择完整无限法则 2022（0.2.989.0）游戏目录。
4. 点击“开始游戏”。游戏运行时请保持启动器开启；关闭启动器将同时结束本次启动的游戏。

启动器会自动获取并连接 CODEYS 游戏服务器。请保持联网和启动器开启。
右上角“访问官网”打开 https://codeys.vip/，“加入 TG 群”打开 https://t.me/codeys_vip。
两个入口在登录前后均可使用，通过默认浏览器打开。
右上角“设置”可选择游戏启动后自动最小化；默认关闭。启用后游戏退出会恢复窗口，手动操作过窗口后尊重你的选择。
窗口位置和大小会自动记住。公告与人数在最小化或游戏运行时降低刷新频率，回到窗口立即更新。
旧版运行缓存会自动清理，保留当前版本、上一版以及仍在使用的版本。
鼠标悬停在公告卡片上时，可滚动滚轮上下切换展开的公告；连续滚动可快速浏览，点击展开卡片仍可阅读全文。
更新弹窗提供“默认 / 精简版 / 完整版”，每次默认勾选“默认”，自动下载与当前启动器一致的版本。
可手动切换；精简版需要 .NET 10 桌面运行环境（x64），完整版包含环境。
选择的版本缺少下载或校验信息时会明确提示，不会悄悄切换成另一版。
更新窗口显示下载进度、速度和预计剩余时间，支持自动重试、暂停和续传；完成校验后才安装。
启动器按客户端已保存的设置选择 DirectX 11 或 DirectX 12，没有设置时使用客户端的 DX11 默认值。
不会改写游戏渲染器设置。已验证的 DX11 和 DX12 客户端均自动启用地图选择：海岛、雪地、随机。
随机会在海岛和雪地中选一张；当前仍按现有服务端规则匹配，后续再对接地图匹配功能。
等待进入大厅后，在原地图卡片/组队设置中查看地图选择。
首次创建角色或登录较慢时会继续等待大厅，不需要手动注入或点击额外的工具。
游戏程序、资源和原有渲染器配置文件保持不变。模块随启动器内置，存放在本机用户目录。
若地图选择未出现，可退出游戏后从启动器重新启动。所选客户端缺失或资源校验失败时会明确提示。
1.1.2 已修复游戏刚创建时模块列表尚未就绪造成的偶发加载失败。

1.1.4 新增“提交反馈”与“检测网络”。提交反馈 在登录前后均可打开官网，官网登录后填写。
网络检测保留10秒延迟/丢包采样，并检查游戏与启动器到服务器的Windows入站、出站防火墙规则及默认策略。
发现可修复的拦截时显示“放行服务器 IP”；点击并同意Windows管理员授权后，
仅放行当前服务器103.143.81.125，保留其他地址的限制。放行后会重新检测。
检测本身不修改规则；管理员策略、覆盖所有程序的阻止和第三方防火墙需手动处理。
网络采样持续10秒。检测到丢包时会提示“检测到丢包，请启动游戏加速器后重新检测。”
在线人数小卡片区分总在线、大厅、对局，每 5 秒刷新，不包含机器人。
未启动游戏时可快速关闭窗口。更新使用独立旧版备份，旧 .old 文件无法删除也不会阻塞后续更新。
若旧版自动更新已经卡住，请从官网重新下载本版并手动运行一次，之后使用修复后的更新逻辑。

网站注册只需账号名、邮箱和密码，注册后即可登录启动器。
启动器不保存密码。登录凭证由 Windows 当前用户加密保护，账号名和游戏目录会被记住。
登录最长有效 7 天，关闭并重开启动器会自动验证并恢复登录，到期后需重新登录。
点击“退出账号”会清除保存的登录状态并撤销凭证；修改密码也会使旧凭证失效。
若退出时断网，启动器会提示服务器尚未确认撤销，并在联网或下次启动时自动重试。
目前没有邮件验证或忘记密码找回功能，请妥善保管密码。

此压缩包仅包含启动器；游戏客户端与资源需自行准备。
网站和启动器首次使用时跟随系统语言：中文系统使用中文，其余语言使用英文。
右上角语言菜单可选择跟随系统、中文或 English，手动选择后会记住。
公告区默认最新一张显示摘要，其余收起正文；每张卡片保留标题和赞、踩、评论入口。
点击折叠标题先在原位置展开摘要，再次点击该卡片的正文区域或“阅读全文”打开全文。
切换摘要会收起上一条，上下公告保留原顺序，只有当前选中的卡片展开。
公告每5秒自动更新；管理员发布的正文保留原来的语言。
登录后可在公告右下角点赞或点踩；同一账号每条公告仅计一种态度，再次点击取消，切换态度会替换原选择。
评论图标可查看和发布多行文字，最多1000字，支持Ctrl+Enter发送；评论显示游戏角色名，正常重启后仍保留。
管理员发表的公告评论显示金色“管理员”；身份由服务器确认，与是否创建游戏角色无关。
“提交反馈”右上角的红点表示你提交的反馈有新回复或处理状态更新。
点击带红点的入口会在浏览器打开对应反馈；浏览器登录同一个账号并查看消息后，红点会自动更新。
公告全文使用深色圆角滚动条，可拖动滑块、点击轨道翻页或使用滚轮；正文仍可选中复制。

游戏启动设置（1.1.7 更新）
在启动器的“设置”中可选择“自动（跟随游戏设置）”、DirectX 11 或 DirectX 12。手动选择只影响本启动器下次启动游戏，不修改游戏的渲染器配置文件。
“启用大厅地图选择”可独立开关：开启后在大厅选择海岛、雪地或随机，关闭后使用游戏原有界面。两项修改均在下次启动游戏时生效；已运行的游戏需先退出再重新启动。
默认自动选择渲染器，开启地图选择。1.1.8 已包含这些设置。

游戏安全系统初始化失败（TP / ACE）
若遇到 Warning (13, 131096, 60)，请在出现错误的电脑上打开“设置 → 检查游戏安全组件”。检查会核对当前渲染器的五个原版组件、启动权限，以及最近的系统阻止记录。
文件缺失或与推荐客户端不一致时，重新获取并完整解压推荐客户端。普通权限下可以退出游戏后，点击“以管理员权限重新打开”进行对照；Windows 会请求授权，取消后保留原启动器。
文件正常仍然报错时，点击“打开已安装的应用”，查找 Anti-Cheat Expert，并按官方维护流程处理。没有对应条目或处理后仍失败时，点击“复制结果”，将结果和完整错误截图一起反馈管理员。
文件检查正常或打开维护页面，都不代表 TP 已经恢复。请重新启动游戏验证结果。

安全组件兼容模式（1.1.8）
此开关默认关闭；需要时可在设置中启用。采用用户提供的签名 ACE-BASE 兼容驱动方案，
不再部署旧版替身 DLL；客户端的原版安全组件、初始化和检查继续执行。
Windows 将请求管理员授权；本次游戏、连接与驱动事务由管理员子进程负责。
请先退出无限法则及其他 ACE 游戏，并在游戏期间保持启动器开启。取消授权不会开始切换。
兼容驱动经完整 SHA256 和 Windows 签名验证后，缓存至 %ProgramData%\LocalROE-ACE-Compat。
每次兼容启动会先自动请求停止 ACE-BASE，再查询并等待已停止状态，最多等待10秒；停止失败或超时会提示并中止本次启动。
确认停止后，才临时修改机器已有、按需启动的 ACE-BASE 服务加载路径；不会替换系统共享驱动。
退出游戏、启动失败或关闭启动器时，先结束本次游戏和连接，再停止兼容驱动并恢复原路径。
恢复完成需确认原路径和已停止状态；若无法卸载、他方改动配置或记录无法确认，保留恢复记录，
按提示重启 Windows 后再试。不要手动删除 lease.json；未知配置不会被自动覆盖。
旧版替身和备份仍按原校验规则恢复；没有原版备份时需重新获取完整客户端。
本次结果记入本次启动日志，随最近10次启动一并清理；管理员保护目录只保留最新结果与必要恢复记录。
